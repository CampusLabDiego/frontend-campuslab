🐇 Administración de RabbitMQ

Gestión de colas, exchanges y bindings. Acceso exclusivo para administradores.

Para las pruebas utiliza nombres con el prefijo demo.campuslab.

Operaciones de administración

Crear cola

60000 milisegundos equivalen a un minuto.

Consultar o eliminar cola

La consulta muestra mensajes listos para entregar y consumidores. La eliminación exige una cola vacía y sin consumidores.

Crear exchange

Direct utiliza coincidencia exacta. Topic permite patrones con * y #.

Eliminar exchange

Eliminar un exchange también elimina sus bindings. Las colas permanecen.

Crear o eliminar binding

La cola y el exchange deben existir. Para eliminar un binding, indica los mismos tres valores utilizados al crearlo.
